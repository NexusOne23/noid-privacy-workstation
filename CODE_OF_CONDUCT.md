# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Short version

- Be respectful. Critique code, not people. Engage in good faith.
- No personal attacks, harassment, or discriminatory language.
- Technical rigour > identity. Everyone from any background is welcome as long
  as contributions hold to the technical bar.
- This is a security-focused project. Private, coordinated disclosure of
  vulnerabilities is required (see `SECURITY.md`).
- Threats, doxing, or coordinated harassment get an immediate ban.

## Enforcement

Maintainers enforce this code. Report violations via the private channel in
`SECURITY.md` (GitHub Security Advisory or the maintainer-profile contact). Reports are kept confidential.

Escalation ladder:

1. Private warning.
2. Public warning with concrete requested behavior change.
3. Temporary ban (1 week – 3 months, scope: issues + PRs + discussions).
4. Permanent ban.

Severe behavior (threats, doxing, coordinated harassment) skips directly to
step 4.
